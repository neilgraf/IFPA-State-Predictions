2. Add the players

Paste one player per line, in seed order. Ratings are optional — add one after the name using a comma, a tab, or just a space (Neil Graf, 1779). Leading seed numbers like 1. are ignored, so you can paste straight from a standings page.

Or import from MatchPlay unverified

Pulls a tournament's field and their IFPA ratings. Needs MATCHPLAY_API_TOKEN set in your own .env file — the server reads it directly, so don't paste a token in here. This path has never been run against the live API, so treat the first run as a test.

3. Review seeds & ratings

Seed order is bracket order — seed 1 is the top seed. Blank ratings default to 1500.

4. Simulation options

Results

Round 1 is fixed by seeding. Later slots show whoever lands there most often across the simulations, with the share of runs they occupy it. Click any match for head-to-head odds and to force a result.

Advancement probabilities

Chance each player reaches a given round. “—” means the player has a bye and never plays that round.
